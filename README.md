Bank Management System

Project Overview
A Python-based Bank Management System developed as a DSA academic project with SQLite database integration.

Features
- Account creation and login
- Deposit and withdrawal
- Balance inquiry
- Money transfer with a ₹20,000 transfer limit
- Transaction history using a linked list
- Transaction search by date and date range
- Transaction filtering by type
- Transaction sorting
- SQLite database integration for persistent records

Technology Stack
- Programming Language: Python
- Database: SQLite
- Concepts: Object-Oriented Programming (OOP), Data Structures and Algorithms (DSA), SQL

How to Run
1. Install Python 3.
2. Download or clone this repository.
3. Open the project folder in VS Code.
4. Run the following command in the terminal:

   `python main.py`

   If required, use `py main.py` on Windows.

Database
The application uses SQLite. The database file is created automatically by the program when its database setup code runs.
